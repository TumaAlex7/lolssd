# Отложенное

Не срочно; большая часть — к следующей пересборке образа Windows.

## Linux внутри Windows

- Программы на hyprtoolkit (hyprpaper при смене обоев) падают в ВМ: без 3D не выделяется буфер.
- Перед запуском ВМ проверять, что система хоста выключена чисто (не в гибернации, журнал ext4
  закрыт); выключать ВМ корректно при выходе из Windows.
- Масштаб: выходы ВМ получают масштаб 1, на панели ноутбука интерфейс мелкий.
- По желанию: своя сборка QEMU с таймером VNC меньше 30 мс (сейчас потолок ~30 кадров).
- Задание при входе пишет «ярлыки: exit status 1» без вывода — разобраться.
- Жесты тачпада — на совести пользователя (назначить им сочетания в настройках Windows).

## Образ Windows

- Раскладка мониторов: Windows по умолчанию дублирует экраны — применять расширенный рабочий
  стол автоматически (CCD `SetDisplayConfig`).
- Обновление файлов Windows-части с раздела LOLSSD без переустановки.
- По желанию: кэш установщика Riot, чтобы не качать игру заново при каждой установке.
