# Отложенное

Не срочно; большая часть — к следующей пересборке образа Windows.

## Режим «Linux внутри Windows»

- [в работе] ВМ вместо WSL: QEMU с WHPX (в Windows Home нет управления ВМ Hyper-V), система хоста
  грузится своим ядром со своего диска по UKI из `lolssd profile`; экран — VNC (только изменения),
  звук — виртуальная звуковая карта QEMU через WASAPI.
- Убрать режим WSL целиком: пусковой дистрибутив, `lolssd-wsl`, MSI WSL в образе, задание
  импорта, `.wslconfig`.
- Жесты тачпада — на совести пользователя (назначить им сочетания в настройках Windows).

## Образ Windows

- Удалить из образа сами компоненты специальных возможностей (то, что лежит в папке «Пуска»
  «Специальные возможности»: экранный диктор, экранная лупа, экранная клавиатура, распознавание
  речи и т. п.), а не только ярлыки или папку.
- Свои ярлыки (Linux, «Restart into Windows (SSD)») — разложить по встроенным папкам «Пуска»,
  папки создавать самим; ярлыки сделать аккуратнее (имена, значки).
- Раскладка мониторов: Windows по умолчанию дублирует экраны — применять раскладку
  автоматически (расширенный рабочий стол, расположение как у хоста по профилю, CCD
  `SetDisplayConfig`).
- Обои по умолчанию — свои, под проект, прямо в образе.
- По желанию: кэш установщика Riot в образе (`RIOT=`), чтобы не качать игру заново.
- Обновление файлов Windows-части с раздела LOLSSD без переустановки.
