# lolssd

League of Legends на внешнем SSD для любого компьютера с Linux.

Внешний SSD с урезанной Windows и лолкой: подключил, загрузился с него, играешь. По желанию твой
Linux продолжает работать внутри этой Windows — та же установка с внутреннего диска, твой
композитор на весь экран, отдельно на каждом мониторе.

Заранее в Linux ничего ставить не нужно: всё, что требуется от системы, делает утилита
`lolssd`, лежащая на самом SSD.

> **Проверено только на железе автора.** На другом может не заработать, ничего не обещаю.

## Статус

Проектирование. Архитектура и план проверок: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Почему так

Vanguard (античит Riot) работает на уровне ядра Windows и не запускается ни через Wine/Proton,
ни в виртуальной машине, ни в облачном гейминге. Остаётся настоящая Windows на настоящем
железе. Этот проект делает её отдельным внешним диском, который не трогает систему хоста.
