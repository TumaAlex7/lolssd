# lolssd

League of Legends на внешнем SSD для компьютера с Linux.

Внешний SSD с урезанной Windows и лолкой: подключил, загрузился с него, играешь. Порядок
загрузки компьютера не меняется: следующая загрузка, как обычно, идёт в Linux. По желанию твой
Linux продолжает работать внутри этой Windows — в виртуальной машине, со своего же диска, своим
ядром, на весь экран каждого монитора.

Заранее в Linux ничего ставить не нужно: всё, что требуется от системы, делает утилита `lolssd`,
лежащая на самом SSD.

> **Версия 0.1. Проверено только на ноутбуке автора** (AMD, Arch Linux, Hyprland). На другом
> железе может не заработать, ничего не обещаю.

## Почему так

Vanguard (античит Riot) работает на уровне ядра Windows и не запускается ни через Wine/Proton,
ни в виртуальной машине, ни в облачном гейминге. Остаётся настоящая Windows на настоящем
железе. Этот проект делает её отдельным внешним диском, который не трогает систему хоста:
что именно он гарантирует хосту — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), §2.

## Что нужно

- компьютер с UEFI, TPM 2.0 и включённой виртуализацией (`lolssd check` проверит);
- внешний SSD от 128 ГБ, лучше NVMe в корпусе USB 10 Гбит/с с UASP;
- для сборки, один раз, на Linux: `qemu-desktop edk2-ovmf swtpm dosfstools ntfs-3g p7zip
  wimlib libisoburn hivex`, Go и ISO Windows 11 с сайта Microsoft;
- для Linux внутри Windows — система хоста с `mkinitcpio` (как Arch).

## Сборка и установка

1. Драйверы для своего компьютера — INF-пакеты (папки с `.inf`, `.sys`, `.cat`; фирменные
   `.exe` обычно распаковываются `7z x`) в одной папке. Они лягут в `C:\Drivers` и поставятся
   при первой загрузке.
2. Установочный ISO со всем внутри (QEMU для ВМ, TigerVNC и драйвер TAP скачиваются сами):
   ```
   make iso ISO=~/Downloads/Win11.iso DRIVERS=~/lolssd-drivers [EDITION="Windows 11 Pro"]
   ```
   Редакция по умолчанию — Home; берите ту, что была на компьютере (активация по цифровой
   лицензии).
3. Поставить Windows на SSD прямо из Linux, в QEMU (**стирает диск**, спросит подтверждение,
   откажется работать не с USB-диском):
   ```
   sudo build/install.sh /dev/sdX dist/iso/lolssd-*.iso [128G]
   ```
   Без размера Windows получает весь диск, с размером — остаток станет разделом `DATA` (NTFS).
   В окне QEMU: «У меня нет ключа продукта» → «Выборочная установка» → незанятое место. Дальше
   без вопросов: локальная учётка, чистка образа, задания, ярлыки; при первом входе ставится
   клиент Riot с игрой — дождаться, пока он предложит играть, и выключить Windows.

## Использование

Раздел `LOLSSD` монтируется как обычная флешка. Утилита запускается через скрипт (udisks
монтирует FAT без права запуска):

```
sh /run/media/$USER/LOLSSD/lolssd.sh check         # подходит ли компьютер, ничего не меняет
sudo sh /run/media/$USER/LOLSSD/lolssd.sh boot     # один раз загрузиться в Windows на SSD
sh /run/media/$USER/LOLSSD/lolssd.sh profile       # один раз: подготовить Linux внутри Windows
```

`boot` ставит одноразовый `BootNext` и перезагружает (`--no-reboot` — без перезагрузки,
`--cleanup` — удалить свою запись из NVRAM). Без утилиты — меню загрузки прошивки (F8/F12/Esc).

В Windows:
- **«Restart into Windows (SSD)»** в «Пуске» — перезагрузиться снова в эту Windows (обычная
  перезагрузка уводит в Linux).
- **«Linux desktop (host)»** — твой Linux в ВМ, на весь экран каждого монитора. Нужен профиль
  (`lolssd profile`) и права администратора (UAC: ВМ открывает диск хоста). Ctrl+Alt+M →
  Exit viewer отдаёт монитор Windows (например, под игру), Ctrl+Alt+F12 на нём возвращает его
  Linux. Выключать — изнутри Linux (`poweroff`), не перезагрузкой Windows.

После обновления ядра на хосте профиль снимают заново: образ загрузки ВМ содержит ядро.

## Linux внутри Windows: что работает

- твоя система целиком: ядро, модули DKMS (VPN и т. п.), systemd, сервисы, `/home`;
- несколько мониторов, курсор ведёт Windows;
- клавиатура через твой keyd, включая Super и Copilot/Menu как правую Super;
- звук — на тех же устройствах PipeWire, что на железе;
- сеть через NAT Windows; работает и zapret.

Чего нет: видеокарты в ВМ (рисует процессор, YouTube в высоком разрешении тянет плохо),
больше ~30 кадров в секунду, программ на hyprtoolkit (hyprpaper при смене обоев). Подробно —
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), §6–7.
